Foundations

Riverpod state foundation

Add production-oriented Riverpod bootstrap and state helpers using manual providers and modern Notifier/AsyncNotifier APIs—without Riverpod code generation.

Generate the preset

kite --state riverpod

Canonical form:

kite state riverpod

Generated output

lib/core/state/ ├── app_provider_observer.dart ├── async_notifier_guard.dart └── riverpod_bootstrap.dart

Included responsibilities

O

Provider observation

Structured debug visibility into provider additions, updates, failures, and disposal.

G

Async guard

Standardized loading, data, and error transitions for production async mutations.

B

Bootstrap

One function to configure ProviderScope, overrides, observers, and retry behavior.

M

Manual providers

No annotations, no riverpod_generator, and no generated state-management source.

Bootstrap the application

void main() {
  WidgetsFlutterBinding.ensureInitialized();

  runApp(
    buildProviderScope(
      child: const App(),
    ),
  );
}

Use async guard behavior

final class ProfileController extends AsyncNotifier<Profile>
    with AsyncNotifierGuard<Profile> {
  @override
  Future<Profile> build() {
    return repository.fetchProfile();
  }

  Future<void> refreshProfile() async {
    await guard(() => repository.fetchProfile());
  }
}
